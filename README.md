# n8n-nodes-videoupscaler — 4K AI Video Upscaler Node for n8n

Official [n8n](https://n8n.io/) community node for **[VideoUpscaler](https://videoupscaler.co)** — automate 1080p, 2K, and [4K AI video upscaling](https://videoupscaler.co/4k-video-upscaler), video denoising, stabilization, face restoration, and 60fps frame interpolation on cloud GPUs directly inside your n8n workflows and AI Agents.

## Why Use `n8n-nodes-videoupscaler`?

1. **Single-Node Wait for Completion (`?wait=45` Long-Polling)**: No need to wire up fragile `HTTP Request` + `Wait` + `IF` polling loops. Enable **Wait for Completion** and the node waits for your 4K MP4 render using server-side long-polling and outputs the permanent `output_url`.
2. **Works as an n8n AI Agent Tool (`$fromAI`)**: Registered with `usableAsTool: true` so you can attach VideoUpscaler directly to an n8n **AI Agent** node and trigger 4K video enhancement from natural-language prompts.
3. **Async Webhook Callbacks (`webhook_url`)**: For multi-minute 4K renders or high-volume [batch video upscaling](https://videoupscaler.co/batch-video-upscaler) queues, pass a `webhookUrl` and receive an instant `POST` callback (`X-VideoUpscaler-Event: task.completed | task.failed`) when the file is ready.
4. **Full Enhancement Controls**: Configure AI engine (`realesrgan`, `realesrgan_anime`, `basicvsr`), [video denoising](https://videoupscaler.co/denoise-video), [video stabilization](https://videoupscaler.co/video-stabilizer), [60fps frame interpolation](https://videoupscaler.co/60fps-video-converter), face restoration, deinterlacing, deflicker, and HDR output.

## Installation

In your n8n instance (Cloud or self-hosted), navigate to **Settings → Community Nodes**, click **Install**, and enter:

```text
n8n-nodes-videoupscaler
```

Or copy one of our ready-to-import workflow JSON templates from **[videoupscaler.co/integrations](https://videoupscaler.co/integrations)** and press `Cmd+V` (`Ctrl+V`) directly on your n8n canvas:

- **3-Node Official Community Node Pipeline**: [`n8n-videoupscaler-node-workflow.json`](https://videoupscaler.co/integrations/n8n-videoupscaler-node-workflow.json)

## Supported Operations

| Resource | Operation | Description |
| :--- | :--- | :--- |
| **Video** | **Upscale** | Submit a public `video_url` (MP4/MOV/WebM or YouTube URL) for `1080p`, `2k`, or `4k` AI enhancement. Optionally waits for completion and returns `output_url`. |
| **Task** | **Get** | Retrieve an upscale task by ID, with optional server-side long-polling (`wait` up to 45 seconds). |
| **Task** | **List** | List recent upscale tasks on your account with status filtering. |
| **Account** | **Get Balance** | Inspect your live credit balance (`remaining_credits`) and per-second resolution rates. |

## Popular Automation Recipes

- **AI Video Generator → 4K → Socials**: Automatically upscale 720p clips generated by Kling, Runway, Sora, or Veo to crisp [4K video quality](https://videoupscaler.co/enhance-video-quality) before publishing to YouTube Shorts, TikTok, or Instagram Reels.
- **Google Drive / S3 Watch Folder → Batch 4K Upscale**: Watch a cloud folder for new product videos, upscale them to 4K, and log the permanent CDN link in Google Sheets.
- **Unblur & Fix Pixelated Footage via Webhook**: Connect customer upload forms (Typeform / Tally / n8n Form Trigger) to [unblur video](https://videoupscaler.co/unblur-video) and [fix pixelated video](https://videoupscaler.co/fix-pixelated-video) automatically.
